# 把视觉反馈变成能复现的验收

先用正常语言复述这四件事：谁固定、谁自己动、输入只影响哪里、移开后如何恢复。把视口和输入设备也写进去。同一版、同一路由和同一时刻对比；排除截图来自旧预览、缓存旧脚本、窗口裁切或减少动效偏好。用原尺寸预览校对字体、画质和文字遮挡。

| 用户的说法 | 先判别什么 | 怎样证明改对 |
| --- | --- | --- |
| “像一张图在转” | 摄影机、整幅纹理是否一起旋转；是否存在尺寸和速度不同的运动参照 | 固定镜头录两段，指针静止时近尘穿过远星，远处气体内部缓动 |
| “鼠标撩一下那一小片” | 输入位置是否来自可见画布；裁切、CSS 像素、DPR 和 Y 轴是否匹配 | 固定随机种子及动画时刻，有输入和无输入各绘一帧，命中区域变化，远处对照块一致 |
| “动效明显一点，手机也看得见” | 手机首屏裁切、近景初始分布和触控事件；手机没有 hover | 无触摸先录自主运动，再横扫局部、松手回落，最后纵向滑动页面。检查取消手势后能恢复 |
| “粗糙、全是白点在跳” | 先看原图、运行图与真实合成图，再定位压缩损失、重复错位叠采样、低分辨率或随机闪点 | 稳定远星、柔焦近尘、粒子淡入淡出，核对裁切后亮区仍有层次；画布像素预算随设备调整 |
| “不突出重点” | 关掉装饰，只看标题、证据、按钮的次序 | 第一次进入的人能指出主营业务及下一步；再恢复最有价值的效果 |

**示例服务星海的取舍**　保留仰望银河的广角构图。远处恒星提供尺度，中层亮带内部缓慢流动，少量近尘有连续轨迹、尺寸变化和局部遮挡。手指只拨动经过的区域，标定半径使用屏幕像素。先确认手机构图，再加运动，再加输入。实录包含无输入、有输入、移开三段。把景深需求写为“我希望看到近物跨过远物”，能避免反复把背景整体旋转。这个题材来自该公司的审美选择；其他项目从自己的业务内容重新立题。

**按作用选择效果**　聚光帮助辨认悬停区域，边缘流光能提示可操作或焦点；3D 倾斜用在产品展示卡，输入聚焦时停稳。磁吸按钮的可点击区域要稳定。滚动显现避免藏住首屏文字；滚动叙事保留自然滚动、锚点和键盘入口。数字滚动呈现已有真实数值。音效默认关闭，由访问者开启，声音之外保留可见反馈。后台批量审核把动效留给选中、正在提交和处理结果。

**降级与成本**　静态画面、标题和操作先出现；关注 reduced-motion、暂停、离屏、切后台和图形上下文丢失。用浏览器测帧间隔和长任务定位持续卡顿，缓存尺寸与重复渐变、限制画布像素和帧率、持续慢帧时逐步降分辨率。按设备比较画质与可操作性。动画截屏可能只抓到一帧甚至黑帧，抽查录屏首中末帧并同时验证图层已启动。

**同一幅画面有静态封面和动态纹理时**，检查预加载、CSS 裁切与渲染器实际选中的图片。手机竖屏切横屏，再趁横图下载时切回竖屏，检查最后显示的图、对齐位置和画布数。每次重新选图都使旧请求失效，包括切回已缓存图片的情况。新纹理可用时再显示动态层，失败时保留当前方向的静态画面。验收顺手再试局部触摸和纵向滚动。主动降低绘制频率后，用帧间隔和视觉表现检查卡顿，单看帧总数会误判。
