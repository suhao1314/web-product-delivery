# 浏览器标签页的图标和标题

按[网站开发四步](project-workflow.md#网站开发四步)安排。先和用户确认本轮需求，然后在电脑端与手机端 UI 图片中评审站点标识。图片与开发方案都明确通过后，才制作、接入正式资源。

访客同时开着多页时，要能认出这是哪个网站、当前页能做什么。标签页里左侧的小图标叫 favicon，旁边的文字由页面的 `<title>` 提供。页面内的主标题可以更完整地说明内容。

## 和用户把图标方向定下来

新建官网、H5 或后台时，在同一次 UI 审图里摆出标签页的样子，附首页和一个内页的标题。先确认已有站名、品牌图和使用许可。项目已有确认过的小图标时直接沿用。需要新做或替换时，和用户商量是否简化现有标志，或沿用品牌色做一个有辨识度的符号。把拟用方向在亮、暗背景下按 16 和 32 像素试摆，选过的方向随图稿确认。开发方案也获得同意后，制作或生成正式素材。没有标志时展示草案即可，正式资源在开发方案通过后导出。

优先出一枚轮廓清楚的方形小写 `favicon.png`。放入项目实际发布的静态资源目录。图案的线条、留白和颜色要在标签大小下看得清。与页面范围相符的各个路由复用同一个标志。框架项目沿用现有元信息入口，静态页在头部引用真实文件。单文件离线演示从交付的独立 HTML 验证，可将小 PNG 内嵌，由目标浏览器实测。添加到手机主屏幕或作为可安装应用时，再按该项目实际需要核对主屏和应用图标。[MDN 的 icon 链接说明](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Attributes/rel#icon)

## 给不同页面取好找的名字

用户已定站名、标题或命名风格时沿用。用户未指定或交给 AI 时，用已有品牌和页面用途直接拟一版，在 UI 稿或交付中给他看。只有涉及另起品牌、命名冲突或业务重点尚不明确时，再把有实际区别的备选拿出来商量。

| 页面 | 默认命名 | 示例 |
| --- | --- | --- |
| 官网首页 | 品牌名在前，后面用简短词说主营 | 桂小递科技｜AI 应用与软件开发 |
| 官网内页 | 用户眼下要找的内容在前，站名在后 | 项目咨询｜微光工作室 |
| 管理后台 | 业务模块在前，后台名称在后 | 商家认证审核｜桂校园管理后台 |

不同页面写不同的标题。控制前半段的长度和清晰度，让窄标签里也能看到关键字。详情按需补公开对象名称。后台标题和浏览历史里避开姓名、手机号、订单号等敏感信息。读到“首页”、模板名、上一个路由的标题时，回头查实际元信息。若项目也关心搜索结果，再单独核对搜索展示。 [MDN 的 title 说明](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/title) · [Google 搜索标题说明](https://developers.google.com/search/docs/appearance/title-link)

两页静态站可在对应页面的 `<head>` 放入下面两行，标题按页改写，图标地址按成品目录定。

```html
<title>项目咨询｜微光工作室</title>
<link rel="icon" type="image/png" sizes="48x48" href="./favicon.png">
```

## 从真实入口验到标签栏

- 同时打开首页、一个内页和一个需要鉴权的页面（项目有时才验）。检查已确认图标和各自标题。直接打开内页、刷新、从页面内跳转再后退。单页应用也要在路由切换后读出当前页标题。
- 用独立的新浏览器会话打开交付的文件或预览链接。部署在子目录时，用实际发布地址核对图标 URL、响应类型和图片可解码。旧站改图标时比较新会话与旧会话，再定位浏览器或站点缓存。
- 实际看见标签栏的小图标与文字，才记录为标签栏实测。浏览器工具只能看网页内容时，回读标题、图标 URL 和图片，按能验证的范围报告。验收官网上线时从正式地址再走一次。
