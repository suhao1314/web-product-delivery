# 微光工作室 · 页面设计约定

访客从[首页](index.html)了解服务或打开作品，带着项目方向到[咨询页](inquiry.html)整理一份可以复制的需求。首页给人阅读和判断的空间，咨询页把空间让给输入和回看。两页共用[样式表](site.css)。

| 设计决定 | 这个站怎么做 | 新增页面时怎么沿用 |
| --- | --- | --- |
| 背景、文字和操作色 | 纸色背景 `--paper` 为 `#f6f6f0`，正文 `--ink` 为 `#1c2b25`，主操作 `--accent` 为 `#557c57`。首屏标题的一处强调也使用操作色。 | 同一组操作里，用实心 `.button` 标出当前最重要的动作。查看案例用带下划线的 `.under`，复制摘要用浅底 `.button.light`。改品牌主色时，连同白色按钮文字一起检查可读性。 |
| 中文标题和表单 | 标题使用 `--serif` 的衬线字体栈，正文和控件使用 `--sans`。在 1280px 视口，首页标题为 72px，咨询页为 52px。 | 作品页标题可以展开，填表页留更多空间给字段。用项目自己的长标题看断行，并在没有首选字体的设备上观察回退。 |
| 页面宽度与顺序 | 桌面内容最多 1080px。宽度不超过 600px 时，首页服务列表排成一列；咨询先显示表单，再显示摘要。手机首页主标题 53px，咨询页 40px。 | 新详情页把“读完之后能做什么”放在作品说明旁。单栏时保护原来的阅读和操作顺序，检查长标题和按钮能否同时完整显示。 |
| 键盘与动效 | 首页与咨询页的主按钮最小高度 46px。键盘焦点有 3px 外轮廓；系统开启减少动效时，锚点使用即时滚动。 | 增加作品链接时从键盘进入并返回，核对焦点可见。装饰图形留在展示区，让表单在打字、确认和复制时保持稳定。 |

**做下一页时怎么验。** 在 390px 和桌面宽度各走一次“首页看案例 → 带着项目方向咨询 → 生成摘要”。从“山野咖啡”作品进咨询时，应已选好该项目；从首页通用咨询入口进入时，应可自行选择方向。记录首先看见的标题、可操作的按钮、窄屏顺序以及一次键盘操作的结果。
